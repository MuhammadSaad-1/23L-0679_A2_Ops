1. ARCHITECTURAL OVERVIEW
-----------------------------------------------------------------------------
Task 7 requires deploying the VisionGuard model inference API to a publicly
reachable cloud server, completely accessible outside the local network. 

The application architecture exposes two distinct interfaces:
1. Web User Interface (HTML):
   - Route: GET / (Upload Form), POST /predict (Result Card), GET /history
2. Headless REST API (JSON):
   - Route: GET /health (Readiness & Configuration probe)
   - Route: POST /api/predict (Multipart/form-data ingestion for Postman & external callers)

When external clients (e.g., Postman, mobile clients, or the local Flask client
in Task 8) send an image to /api/predict, the service executes in-memory 
inference with zero disk retention and returns structured JSON:
{
  "status": "success",
  "filename": "sample_real_0.png",
  "verdict": "RealArt (Human Created)",
  "verdict_code": "REAL",
  "confidence_pct": 94.25,
  "confidence": 0.9425,
  "raw_probability": 0.9425,
  "decision_threshold": 0.5,
  "latency_ms": 22.4,
  "model_architecture": "MobileNetV2_Champion_v2",
  "caveat": "High statistical certainty on benchmark features..."
}

3. POSTMAN API VALIDATION PROCEDURE
-----------------------------------------------------------------------------
To generate the required Postman evidence for the PDF report:

1. Launch Postman (or use Postman Web / curl).
2. Create a new request:
   - Method: POST
   - Target URL: {{BASE_URL}}/api/predict
     (e.g., http://localhost:5000/api/predict for local dry-run,
      or https://<your-cloud-domain>/api/predict for cloud)
3. Headers:
   - (Postman automatically sets Content-Type: multipart/form-data with boundary)
4. Body:
   - Select radio button: "form-data"
   - Key: "file" (Hover over the Key input, change dropdown from "Text" to "File")
   - Value: Choose any sample image (e.g., eda_outputs/sample_real_0.png)
5. Click "Send":
   - Verify Status: 200 OK
   - Response Body format: JSON
6. Negative Security Rejection Test:
   - In the Body form-data, change file to a .txt file (e.g., README.md)
   - Click "Send"
   - Verify Status: 400 Bad Request
   - Response Body: {"error": "Unsupported extension '.md'...", "status": "failed"}
